\textbf{Feedforward}
\begin{itemize}
  \item Factor-of-4 rule of thumb (8/3 for GLUs) is standard (with some evidence)
\end{itemize}
\textbf{Head dim}
\begin{itemize}
  \item Head dim*Num head = D model is standard -- but low to no validation
\end{itemize}
\textbf{Aspect ratio}
\begin{itemize}
  \item Wide range of `good' values (100-200). Systems concerns dictate the value
\end{itemize}
\textbf{Regularization}
\begin{itemize}
  \item You still `regularize' LMs but its effects are primarily on optimization dynamics
\end{itemize}
