- Page geometry: DL4NLP is 4:3, this course is 16:9. 43 frames overflowed. Fixed
  per frame by scaling \includegraphics sizes by 0.85 (49 edits) and, for
  text-only frames, a \small / \footnotesize line marked "% fit16:9". Three frames
  still did not fit without touching text: "Multi-task training vs Instruction
  tuning" and "Chain-of-thought few-shot prompting motivation" use
  [allowframebreaks]; "Decoding Example (1)" has its three \vspace{0.5cm} reduced
  to 0.15cm. No text was changed.
- Source bugs fixed (each marked in the .tex):
  - chapter09-llm/slides-94-deepseek inputs newway.tex twice; that file does not
    exist anywhere in the DL4NLP repository. Commented out.
  - ch08/slides-81-intro: two Hugging Face URLs contain an unescaped '#' inside a
    non-fragile frame (fatal error); escaped as \#.
  - ch08/slides-81-intro "Generate Function": nested itemize without a parent \item;
    an empty \item[] added.
  - chapter09-llm/reinforce.tex (input by slides-94-deepseek) inlined.
- Preamble: same DL4NLP macro set as session 8, plus xspace and the \cotp,
  \cotpfull, \cotpfullcap macros from the ch09 file preambles. Same deck-local
  bold-typewriter font substitution as session 8.
