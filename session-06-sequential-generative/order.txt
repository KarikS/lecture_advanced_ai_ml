This session compiles to a single deck: slides-sequential-generative.tex

Built 2026-09-14. Kept as one deck despite its size (~260 raw source pages before
merging) per the user's explicit decision during brainstorming: "It can be long,
that's fine" — no split into two sessions, no hard trimming purely for page-count
reasons (unlike session-05-cnn's Modern Architectures, which was trimmed hard).
Quality-motivated trims (redundancy, derivation depth) were still applied where
the user asked for them; see below.

One real bug hit and fixed during the build: `figure/embed1.png` (Word
Embeddings frame, sourced from rnn/plots/, not rnn/figure/ like the rest of
the RNN figures) was missed in the first figure-copying pass and caused a
fatal "file not found" error on first build. Root cause: I copied RNN
figures only from rnn/figure/, not checking that one image lived in
rnn/plots/ instead. Fixed by copying it from the correct directory; a
systematic check (grep every \includegraphics path against what's actually
in figure/) confirmed no other figures were missed before the final build.

Final build: 232 pages, no errors, no missing figures (confirmed via log
grep for "not found"/"Undefined"/"! LaTeX Error", and by rendering sample
pages across the deck, including the new Diffusion Models TikZ diagram, with
pdftoppm). Larger than every other session in this course by a wide margin
(sessions 1-5 run 74-138 pages) --- an intentional outcome of the user's
"it can be long" decision, not an oversight.
